# Heads

A continuation of [insou](https://github.com/insou22)'s **Heads** the original plugin from [github.com/insou22/Heads](https://github.com/insou22/Heads), posted on [SpigotMC](https://www.spigotmc.org/resources/heads.26467/) in **July 2016**.

It was a well-known free heads GUI with over **120,000+ downloads**, and a catalog of **2,000+** custom skulls. The last official build stopped at **1.8–1.12**. This repo exists to bring that same plugin forward so people can keep using the original on later versions.

## What it does

`/heads` opens a category menu. Pick a category, click a skull, and it drops at your feet.

Permission: `heads.use`
